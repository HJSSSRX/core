项目概要

项目定位应对网络犯罪的综合AI平台：信息收集 + 大数据 + 渗透测试 + 电子取证 + CTF
核心架构统一核心框架 + 领域插件（Supervisor多Agent协作 + DAG任务引擎）
技术栈Python 3.12 主体 + Rust (PyO3) 性能层
团队规模~10人（湖南警察学院），水平不一，每周2×2h线下同步
历史教训旧项目缺乏架构规划、臃肿、无法协作 — 本次从零开始，注重架构设计
预计规模~73个文件，~8,200 LOC，5个实施阶段

Phase A — 架构对齐决策（22项，全部已确认）

Q1 — 项目覆盖范围 ✅ 已确认

决策: 选项C扩展 — 信息收集 + 大数据 + 渗透测试 + 电子取证 + CTF，定位为"应对网络犯罪的综合平台"

扩展范围，不局限于单一取证领域，打造安全从业者的一站式平台
Q2 — 范围分解与组织方式 ✅ 已确认

决策: 选项A — 统一核心 + 领域插件

轻量 Agent 调度核心 + 各领域独立插件，避免旧项目臃肿问题，支持并行开发
Q3 — Agent 架构模式 ✅ 已确认

决策: 选项B — Supervisor 多Agent协作模式（调度Agent分解分配，专业子Agent各司其职）

取证任务有自然的分解层次，DAG 比 P2P mesh 更适合
Q4 — 核心技术栈 ✅ 已确认

决策: 选项C — Python 3.12 主体 + Rust (PyO3) 性能扩展

Python 有最好的 AI/取证/安全工具生态，Rust 处理大数据和文件解析的性能瓶颈
Q5 — 插件系统设计 ✅ 已确认

决策: 选项C — Python 抽象类 + MCP Server 双模

内部深度集成用 Python ABC，外部 AI 生态对接用标准 MCP 协议
Q6 — LLM 后端策略 ✅ 已确认

决策: 选项C — 统一 LLMBackend 抽象层 + 全局离线开关

支持: OpenAI / Anthropic / DeepSeek / Ollama / vLLM。Agent 代码完全不感知后端差异。Sensitivity 路由：高敏感→本地模型，低敏感→云端，FORHACKER_OFFLINE=1 全局覆盖

一套代码覆盖所有场景（比赛在线/决赛离线/开发/训练/真实案件）
Q7 — Agent 间通信协议 ✅ 已确认

决策: 选项C — MessageBus 抽象层，默认进程内 InProcessBus，可选 Redis/NATS 分布式

与 LLM 层、插件层一致的抽象哲学：抽象接口 + 多实现，单机零依赖
Q8 — 任务编排引擎 ✅ 已确认

决策: 选项C — DAG 基础 + 运行时动态追加节点（add_task 带环检测，原子写盘）

有 DAG 才有审计链和断点续跑；动态扩展保证探索性调查的灵活性
Q9 + Q21 — 数据层与服务器角色 ✅ 已确认

决策: PostgreSQL + 本地文件系统（服务器仅做 Syncthing 中继 + PostgreSQL 元数据）

证据存本地 cases/<case-id>/evidence/，服务器 2C8G 20G 无法存储检材。两条数据路径：热路径用 shared/ YAML，冷路径用 PostgreSQL

服务器配置低只做辅助；检材几百GB，各电脑自行下载
Q10 — 安全隔离与沙箱 ✅ 已确认

决策: 选项A — Docker + WSL2 Firecracker 本地分级隔离

风险分级：LOW→Docker（网络允许），MEDIUM→Docker（网络限制），HIGH→Firecracker microVM（完全隔离），UNKNOWN→默认 HIGH

服务器配低；笔记本是主力。断网决赛场景完整可用。HIGH 任务 KVM 不可用时直接 BLOCK，不静默降级
Q11 — 用户界面 ✅ 已确认

决策: 选项B — CLI 优先 + Web Dashboard 辅助可视化

CLI (click/typer) 用于比赛速度和可脚本化；Web (FastAPI + Jinja2) 仅本地，三大视图：Case Overview / Timeline / Evidence Map

CTF 比赛场景 CLI 效率最高；复杂可视化走本地 Web

六大设计原则

#原则说明
1抽象优先，避免锁定 每个基础设施组件提供抽象接口+至少两种实现（零依赖默认+可选扩展）。Agent 代码不直接导入具体后端
2程序做搬运，AI做判断 文件同步、哈希验证、格式校验、工具执行由确定性程序处理；AI只负责解释、关联、策略、生成。AI绝不调用HTTP做协作
3置信度分级 所有输出标注 ✅已验证 / ⚠️推测 / ❌未知。task_confidence(HIGH|MEDIUM|LOW) + evidence_confidence(verified|inferred|unknown) 双字段
4模块自治，核心统一 每个插件独立开发，核心定义接口契约。Cell 可在边界内自由实验；核心仅通过 PR 变更
5知识是一等资产 每个案件、每个任务、每个发现汇入共享知识库。纯 Markdown + YAML frontmatter，人类可读、git可diff、零依赖可搜索
6自我改进是基础设施 MetaAgent 定时巡检、发现优化方案、人类审核后执行。系统运行越久能力越强

团队文化（非技术但同等重要）

  • Cell 制，不是部门制 — 每个人 + AI = 一个独立生产力单元
  • AI 是真·生产力，不是噱头 — AI 使用方案本身是核心竞争力
